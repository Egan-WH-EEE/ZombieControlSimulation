# ZombieControlSimulation
Python-based zombie apocalypse simulation used to optimise control using Model Predictive Control (MPC). Zombies continuously spawn in the centre of the map and pursue the player at a slightly slower speed bounded to a rectangular area. The player can be controlled manually (WASD) or  autonomously using MPC.
